# Design for Delight Principles

# Zero Cognitive Load

## What it means

1. Design interfaces that dont just minimize cognitive load but rather represent Zero Cognitive load
2. Zero Cognitive means a user interface that *does not require System 2 even when being used for the first time*
3. What it feels like to a new or returning user
    1. doesn’t need instructions,
    2. performs the right first action instinctively,
    3. gets an immediate, rewarding response,
    4. feels “this makes sense,” and
    5. never switches into analytic mode.
    6. experiences flow and not cognition

## Why

1. Feels “Effortless”
2. Habit forming
3. Higher Funnel conversion

## Principles in order of priority

1. **Zero Clutter**
    1. Each screen contains *exactly and only* the elements (words, images, assets) that are both *necessary and sufficient* to achieve the outcome. No more, no less
2. **Use fewer words**
    1. If you can communicate something in one word, don't use two. Every extra word competes for attention.
    2. Design for Scanning, Not Reading.
    3. Don’t repeat
3. **Smart Defaults and Auto completes**
    1. Do not ask users to input information or perform actions that you can perform automatically
4. **Progressive Disclosure / One page, One context**
    1. Reveal complexity only as needed
5. **Strong and Logical Visual Hierarchy**
    1. Use font weight, contrast, indentation as required to creating a logical visual hierarchy. Let the eye naturally find what’s important
    2. Do not use multiple columns that require scanning top to bottom and left to right.
6. **Instant Feedback**
    1. Every user interaction must give an immediate and intuitive feedback within under 100ms
7. **Consistency**
    1. Repeat design elements and patterns
8. **Familiar Mental Models**
    1. Map interactions to patterns users already know.
9. **Reduce Analytical Choices**
    1. Each time a user has to make an analytical choice it requires a cognitive load

# Engage the Senses

1. **Why**
    1. Exceptionally pleasing sensory inputs such as sights and sounds trigger dopamine release
2. **How**
    1. Build in haptics and pleasing sounds on relevant events / completion of relevant actions
    2. Add delightful micro animations when the user achieves, accomplishes, completes a task, milestone, activity

# Purpose-built Unique Design

1. **What**
    1. Where relevant for high frequency features build a custom purpose-built design that departs from the traditional forms and buttons to provide a much more fit-to-purpose interface
2. **Why**
    1. Novelty triggers dopamine release
3. **How**
    1. For a high frequency feature understand what the user is trying to achieve and instead of going with the convention, custom design the interaction to uniquely solve for the challenges of the user. Examples of this
        1. Apple iPod Wheel: The iPod's click wheel was designed for easy scrolling and selection of music tracks, allowing users to navigate long playlists efficiently with just one finger
        2. Tinder's Swipe to Like/Dislike: Prior to Tinder dating apps had lists with buttons and detailed profiles. Tinder truly understood that the primary decision making criteria tends to be physical attraction. It changed the entire interface by using the entire screen for just one thing - the photo, and a simple gesture - swipe right to like and swipe left to dislike mechanism
    2. IMPORTANT: This must not be done in violation of the Zero Cognitive Load principle. Use “Familiar Mental Models” to ensure the unique design feels intuitive and natural and does not require System 2
